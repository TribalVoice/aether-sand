# Aether Sand

Granular ambient synthesizer in the Aether series.

Load any audio file and explore wet grains, massive reverb (SuperMassive-inspired), Freeze drones with optional Smear and Note Filter, particle visualisation, MIDI control, presets, and high-quality WAV export.

**Play:** open `index.html` in Chrome, Edge, or Safari.

**Features:**
- Granular synthesis (Haze / Tunnel / Freeze modes)
- Massive convolution reverb
- Smear for Freeze texturalisation
- Tunable resonant Note Filter
- MIDI in (notes set position, CCs for parameters)
- Presets (localStorage)
- Record to 16-bit stereo WAV
- Lookahead scheduler for stable timing
